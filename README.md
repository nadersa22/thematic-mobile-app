# Thematic Mobile App

This is a mobile app built with React Native and Expo.

The app is inspired by the Thematic web app and includes:
- Home screen
- Explore screen
- Playlists screen
- Playlist details
- Header with search and user flyout
- Simple UI components and mock data

## Tech Used
- React Native
- Expo
- TypeScript
- React Navigation

## Features
- Browse playlists
- Explore songs by genre
- Open playlist details
- Search UI
- User menu / flyout
- Responsive mobile layout

## Notes
This project was built as a front-end mobile practice/task.
Some sections use mock data and some actions are placeholders.
